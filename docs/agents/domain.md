# Domain docs

## Перед исследованием проекта

Прочитай `GLOSSARY.md` в корне и относящиеся к задаче ADR
из `docs/adr/`.

Если документов нет, продолжай работу. Они создаются
по мере определения терминов и принятия решений
через навык domain-modeling.

## Структура

Single-context:
- `GLOSSARY.md` — термины проекта.
- `docs/adr/` — архитектурные решения.

## Использование

Используй термины из глоссария в задачах, коде и тестах.
Пробелы в терминологии отмечай для domain-modeling.
Если предложение противоречит ADR, явно укажи документ
и причину пересмотра решения.
