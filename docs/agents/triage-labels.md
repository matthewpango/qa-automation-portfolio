# Triage labels

В локальных задачах метка записывается в строке `Status:`.

| Роль | Метка | Значение |
|---|---|---|
| needs-triage | needs-triage | Требуется оценить задачу |
| needs-info | needs-info | Требуются дополнительные сведения |
| ready-for-agent | ready-for-agent | Готова к реализации агентом |
| ready-for-human | ready-for-human | Требует реализации человеком |
| wontfix | wontfix | Выполняться не будет |

Для задач Wayfinder используй состояния claimed/resolved,
описанные в `issue-tracker.md`.
