# Issue tracker: Local Markdown

Задачи и спецификации хранятся в `.scratch/`.

- Одна фича — одна папка `.scratch/<feature-slug>/`.
- Спецификация — `spec.md` внутри папки фичи.
- Каждая задача — отдельный `issues/<NN>-<slug>.md`, начиная с `01`.
- Состояние triage — строка `Status:` в начале задачи.
  Значения определены в `triage-labels.md`.
- Обсуждение дописывается в конец задачи под `## Comments`.

«Опубликовать в трекере» означает создать соответствующий файл.
«Получить задачу» означает прочитать файл по указанному пути.
Если указан только номер, ищи его среди локальных задач;
при неоднозначности уточняй фичу.

## Wayfinder

- Карта исследования: `.scratch/<effort>/map.md`,
  с разделами Notes, Decisions-so-far, Fog.
- Дочерние задачи: `.scratch/<effort>/issues/NN-<slug>.md`.
- `Type:` — research, prototype, grilling или task.
- Зависимости: `Blocked by: NN, NN`.
- Выбирай первую по номеру открытую, незанятую задачу,
  у которой все зависимости имеют `Status: resolved`.
- Перед работой запиши `Status: claimed`.
- После работы добавь ответ под `## Answer`, установи
  `Status: resolved` и добавь краткий итог со ссылкой
  в Decisions-so-far карты.
