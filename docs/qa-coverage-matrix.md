# Матрица покрытия ParcelQuote

Дата: 2026-11-09. Основание: [тестовая стратегия](qa-strategy.md).
Исходный снимок: `f31c7d4`, 46 тестов. После этапов API/UI: 82 теста, включая 63 HTTP API-теста и 11 UI-сценариев Playwright.
Приоритеты и новые сценарии предложены для следующего этапа автоматизации.

«Есть» означает, что указанный критерий найден в текущем тесте, а не полноту
всех комбинаций. «Частично» перечисляет конкретный остаток. HTTP-набор в `tests/api/` запускается против Docker через BASE_URL. Внутренние
проверки 500 и изменённых тарифов остаются в `tests/app.test.ts`.

Риски R1–R6 определены в стратегии. Все строки P0 обязательны до завершения
соответствующего этапа; статус «частично» не засчитывается как полное покрытие.

## Как выполнять в первую очередь

1. CALC-02 и CALC-04: закрыть известные пробелы независимых числовых эталонов.
2. API-01–API-08 и ROUTE-01–ROUTE-04: HTTP-набор против Docker, с явным
   разделением позитивных данных, негативных классов и контрактных проверок.
3. UI-02–UI-04: дополнить пользовательские переходы состояния.
4. ENV-01–ENV-02: перенести реальный запуск в CI и сохранять доказательства.
5. P1-расширения выбирать по изменению продукта и найденным дефектам.

Для каждого добавленного теста в этой матрице указать файл и название сценария.
Не менять «частично» на «есть» только потому, что появился один похожий тест.
Если критерий не проверялся из-за окружения, записать «блокировано», причину и
что требуется для повторного запуска.

## Правила проверки и отчёта

- Позитивные результаты вычислены независимо от функций продукта.
- HTTP-проверка использует настоящий сервер; network mock не заменяет её.
- Сценарий содержит различающие утверждения: маршрут, оплачиваемый вес,
  составляющие и итог, когда это нужно для обнаружения ошибки.
- Один прогон всех пар не доказывает правильность всех цен без эталонов.
- Новые ошибки дают воспроизводимый вход, ожидаемое/фактическое поведение,
  SHA и окружение. Ручное наблюдение не считается автоматизированным покрытием.
- Поля Coverage/Flakiness в отчёте остаются «не измерено», пока нет измерений.
