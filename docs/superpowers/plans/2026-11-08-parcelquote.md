# ParcelQuote Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** Создать локально запускаемый калькулятор доставки с API и русской веб-страницей для последующего QA-портфолио.

**Architecture:** Один Fastify-сервер обслуживает API и три статических файла страницы. Чистая функция рассчитывает цену по тарифам из конфигурационного файла. Состояние запросов не сохраняется.

**Tech Stack:** Node.js 24, TypeScript, Fastify 5, HTML/CSS/JavaScript; node:test для минимальных проверок сервиса, Playwright для небольшой браузерной проверки.

**Spec:** `docs/superpowers/specs/2026-11-08-parcelquote-design.md`.

## Global Constraints

- Интерфейс, сообщения об ошибках и README на русском.
- Названия полей API и идентификаторы кода на английском.
- Без базы данных, аккаунтов, истории и внешних сервисов.
- Все поля обязательны. Неизвестные поля отклоняются.
- Границы включены; строки вместо чисел не преобразуются сервером.
- Тарифы учебные; изменения требуют перезапуска.
- Объёмный и расчётный вес перед округлением вверх не округляются.
- Полный набор портфолио-тестов, CI/CD и деплой остаются следующими этапами.
- Проза репозитория не использует длинное тире (правило AGENTS.md).

## Review Focus

1. Вес 0.29 и 1.250 принимается, 1.251 отклоняется: учитывать ошибки двоичной арифметики.
2. Объёмный вес чуть больше целого повышает оплачиваемый вес, без предварительного округления.
3. Fastify не удаляет неизвестные поля и не преобразует строки в числа.
4. Пустое поле и неправильный разделитель в форме не превращаются в допустимое число.
5. Поздний ответ после изменения формы не показывает цену для старых параметров.

## Task 2: HTTP API, валидация и сервер

**Files:** `src/app.ts`, `src/server.ts`, `tests/api.test.ts`.

**Interfaces:**
- Consumes: QuoteInput, QuoteResult, calculateQuote из Task 1.
- Produces: `buildApp(): FastifyInstance`, который не слушает порт автоматически.
- Produces: POST /api/quote, ответ QuoteResult или `{ errors: Array<{ field: string | null; message: string }> }`.
- Сервер: HOST по умолчанию 127.0.0.1, PORT по умолчанию 3000; ошибку запуска вывести и завершиться с ненулевым кодом. SIGINT/SIGTERM закрывают сервер.

- [x] Написать tests/api.test.ts через buildApp().inject(), закрывать приложение после проверки. Успех: statusCode=200, totalRub=220, currency='RUB'.
- [x] Параметризовать проверки 400: отсутствующее поле, null, строка вместо числа, extraField, вес ниже 0.1/выше 30/1.251, сторона 0/101/1.5, расстояние 0/3001/1.5, неверный deliveryType и строка вместо fragile. Для каждого проверить поле ошибки и непустое русское сообщение.
- [x] Проверить принятие граничных 0.1 и 30 кг, сторон 1 и 100, расстояний 1 и 3000, веса 0.29 и 1.250. Проверить несколько ошибок в одном ответе без зависимости от порядка.
- [x] Проверить malformed JSON: 400 и field=null; text/plain: 415 и единая форма ошибок. Проверку 500 выполнить отдельным намеренно падающим маршрутом тестового приложения с тем же обработчиком ошибок: ответ не содержит stack и текст исключения.
- [x] Запустить `npm run test:unit`, получить ожидаемые отказы новых тестов.
- [x] Реализовать buildApp и схему: additionalProperties=false, все поля required, coerceTypes=false, removeAdditional=false, allErrors=true. Шаг веса 0.01 проверять с ограниченной погрешностью двоичной арифметики, принимая 0.29 и отклоняя 1.251. Сообщения схемы переводить в согласованную форму, включая неизвестное поле.
- [x] Реализовать сервер. Настроить обработку ошибок 400/415/500; не журналировать полные тела запросов и данные пользователя. Не добавлять публичный тестовый маршрут.
